# Ritual README

**A symbolic GitHub profile updater for async builders, neurodivergent coders, and mythic technologists.**

This lightweight tool updates your GitHub profile README with a random quote and a UTC timestamp. It runs daily using GitHub Actions to ritualize your public presence—even when you're off-grid.

---

## Features

- Pulls from a customizable `quotes.txt` file
- Updates your `README.md` with one symbolic quote per cycle
- Includes a timestamp for rhythm tracking
- Easy to extend with lunar phases, emotional weather, or personal rituals

---

## Example Output

> _"I am already standing inside the dream I once whispered in silence."_  
> _Updated: 2025-04-30 11:13 UTC_

---

## Getting Started

1. Clone the repo
2. Add your own quotes to `quotes.txt`
3. Customize `update_readme.py` as needed
4. Enable the included GitHub Action to run daily at 10:00 UTC
